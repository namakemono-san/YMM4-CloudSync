◆ v0.4.0 - 2026-8-28

重要
- 必要な YMM4 のバージョンが 4.55.1.1 以降になりました
  アセットタブが YMM4 のアイコン・コントロール・ファイル種別設定・
  タイムライン追加コマンドを利用するためです
- Google ドライブの権限をドライブ全体に変更しました
  ブラウザや Google ドライブアプリから直接置いた素材も表示・操作できます
  権限が変わるため、Google ドライブは再ログインが必要です

新機能
- 「アセット」タブを追加
  - クラウド上の Assets フォルダを、エクスプローラー風にブラウズできます
    - ツールバーは 1 行構成 (戻る / 進む / 上へ / 接続先 / アドレスバー /
      新しいフォルダー / アップロード / 絞り込み / 検索 / メニュー)
    - 戻る・進むでフォルダーの移動履歴をたどれます
    - 表示は 一覧 / 並べて表示 / 大きいアイコン の 3 種類。Ctrl + ホイールで切り替わります
    - 並べ替えは 名前 / 種類 / サイズ / 更新日時 と 昇順・降順。常にフォルダー優先で、
      名前は数字を数値として扱う自然順です
    - アイコンは Windows のファイル種別アイコンを使用します
    - 詳細 (種類・サイズ・更新日時・状態) は行のツールチップに表示します
    - 絞り込みは 動画 / 音声 / 画像 / テキスト / フォルダー / その他 の個別切り替えと、
      名前での検索、取得済みのみ表示
    - ファイルの種類判定には YMM4 本体の拡張子設定を使用します
  - フォルダーをダブルクリックすると中に入れます
  - ファイルをダブルクリックすると、ダウンロードしてタイムラインに追加します
  - ダウンロードした素材は、一覧からタイムラインへドラッグしても配置できます
    - 複数選択したままドラッグすることもできます
    - ドラッグ中はカーソルに対象名が表示され、元の行が薄くなります
  - 素材のアップロード、フォルダ作成、削除に対応
    - エクスプローラーから一覧へファイルをドロップしてもアップロードできます
  - 各行に 未取得 / 取得中 / 取得済み / 古い / 失敗 の状態を表示します
    - クラウド側が更新されると「古い」になり、そのままでもドラッグは可能です
  - ダウンロードは 3 件まで同時に実行され、行ごとに中止できます
修正
- Google ドライブで、フォルダーの識別子が空のときに不正な検索条件を送っていた問題を修正
- Google ドライブへのアップロードで、通信失敗や中止のときに
  「アップロード後のファイルIDを取得できませんでした」という無関係なメッセージが
  出ていた問題を修正。失敗時は本来の理由を表示します
- 連携情報の保存中に「別のプロセスで使用されています」で失敗することがある問題を修正
- ダウンロードの一時ファイル名が重複し、同じファイルへの操作が重なると
  失敗することがある問題を修正

その他
- エラー報告の送信対象を絞り込むように
  - 本プラグインのコードを含まない例外 (YMM4 本体や他プラグインで発生したもの) は送信しません
  - 利用者による中止、および DNS 解決失敗などの一時的な通信エラーは送信しません
- 設定タブに「アセット保存先」を追加
  - 既定は %LOCALAPPDATA%\YMM4CloudSync\Assets です
  - YMM4 は素材を絶対パスで参照するため、このフォルダを移動・削除すると
    素材を配置済みのプロジェクトのリンクが切れます

◆ v0.3.0 - 2026-8-27

修正
- Dropbox で 8MB 未満のファイルのアップロードが必ず失敗する問題を修正
- 通信エラーやレート制限（429 / 503）時に再試行が行われない問題を修正
- 一時的な通信エラーで Google Drive の連携情報が消えてしまう問題を修正
- 更新通知が表示されない問題を修正
- OneDrive でファイル一覧が途中までしか取得できない問題を修正
- 設定タブの <ProjectDir> タグが機能していなかった問題を修正
- 拡張子の関連付け解除が管理者権限なしでは失敗する問題を修正
- ダウンロード時の差し替えを中断しても既存ファイルが失われないように修正
- パッケージ作成の進捗が 100% を超えることがある問題を修正
- Dropbox のプロジェクト一覧でフォルダが末尾に並ぶ問題を修正
- 設定の入力中に 1 文字ごと・かつ二重にファイル保存されていた問題を修正
- ボタンの連打で処理が二重に開始されることがある問題を修正
- OneDrive で一度もアップロードしていない状態のプロジェクト一覧がエラーになる問題を修正
- 空のプロジェクトでも「プロジェクトを保存」ボタンが押せてしまう問題を修正
- Dropbox の認証用ポートが使用中のときに連携できない問題を修正
- Dropbox の認証中にブラウザを閉じると処理が終わらない問題を修正
- ツールを再表示するたびにクラウドへの再接続が走っていた問題を修正
- .ymmx のダブルクリックで開いた場合に、設定したプロジェクト保存先が使われない問題を修正
- 破損した .ymmx を開いたときのエラーメッセージを分かりやすく修正
- 連携情報の保存が中断された場合にファイルが壊れないように修正
- プロジェクト一覧の取得を中止できるように修正
- クラウド上のフォルダがプロジェクト一覧に表示されることがある問題を修正
- プロジェクトを開く処理を高速化
  - クラウド側が更新されていなければ、ダウンロードも展開もせず既存のプロジェクトを開くように
  - 更新されている場合も、内容が変わっていない素材は展開し直さないように
  - 右クリックメニューの「再取得して開く」で、常にクラウドから取り直せます
- パッケージ作成を高速化
  - 圧縮済みの素材 (動画・音声・画像) を再圧縮しないように
  - ハッシュ計算と書き込みを1回の読み込みにまとめ、ファイルの読み込み量を半減
- 大文字小文字だけが異なるパスで同じ素材が二重に梱包される問題を修正

新機能
- プロジェクトを .ymmx ファイルとしてローカルに書き出せるように
  - 素材をまとめた1ファイルになるため、そのまま配布・受け渡しが可能
  - クラウドと連携していなくても使用可能
- WebDAV に対応 (Nextcloud / ownCloud / InfiniCLOUD など)
  - 複数の接続先を登録可能
  - Basic / Digest 認証に対応
  - Nextcloud / ownCloud では大きいファイルを分割送信し、中断時は続きから再開
- アップロード・ダウンロード・パッケージ作成・展開を「中止」ボタンで取り消せるように
- ハッシュ値が一致しない場合に、開くかどうかを選べるように
- プラグイン画面からプロジェクトを開く際も、既存プロジェクトの上書き確認を表示するように

プライバシー
- エラー報告に含まれるファイルパスから Windows ユーザー名を除去するように
- エラー報告を本プラグイン専用のクライアントに分離し、YMM4 本体や他プラグインで発生した例外を送信しないように

セキュリティ
- セキュリティ強化のための修正が含まれます
- パッケージに含まれていないファイルを参照している場合、その参照を取り除いたうえで開くように
- 詳細は SECURITY.md の方針に基づき、公開を控えています

◆ v0.1.2 - 2026-01-05

新機能
