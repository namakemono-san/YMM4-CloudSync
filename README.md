# YMM4 Cloud Sync

**YMM4 Cloud Sync** は、**YukkuriMovieMaker4**（以下、YMM4）のプロジェクトを  
**クラウドストレージと同期・管理**するためのプラグインです。

ローカル環境に依存せず、複数環境での作業やバックアップを簡単に行うことを目的としています。

> [!IMPORTANT]
> 本プラグインは **β版（開発中）** です。  
> 仕様変更や不具合が発生する可能性があります。

## 主な機能

- YMM4 プロジェクト（`.ymmx`）のクラウド保存
- クラウド上のプロジェクト一覧表示
- プロジェクトのダウンロード・削除
- クラウド上のプロジェクトを直接開いて編集
- プロジェクトを `.ymmx` ファイルとしてローカルに書き出し（クラウド連携なしで利用可能）
- 素材（アセット）のクラウド保存と、タイムラインへのドラッグ＆ドロップ配置

現在対応しているサービスは以下の通りになります。
- Google Drive
- Dropbox
- OneDrive
- WebDAV (Nextcloud / ownCloud / InfiniCLOUD など)

※ 今後、対応クラウドサービスの追加を予定しています。

### アセット（素材）について

「アセット」タブでは、クラウド上の `Assets` フォルダを、エクスプローラー風にブラウズできます。

- **フォルダーをダブルクリック**すると中に入れます。**ファイルをダブルクリック**すると、ダウンロードしてタイムラインに追加します
- ダウンロードした素材は、一覧から YMM4 のタイムラインへ**ドラッグして配置**することもできます（複数選択も可）
- ツールバーは 1 行構成（戻る / 進む / 上へ / 接続先 / アドレスバー / 新しいフォルダー / アップロード / 絞り込み / 検索 / メニュー）。**戻る・進む**で移動履歴をたどれます
- 表示は **一覧 / 並べて表示 / 大きいアイコン** の 3 種類。**Ctrl + ホイール**で切り替わります。アイコンは Windows のファイル種別アイコンです
- 並べ替えは名前 / 種類 / サイズ / 更新日時、昇順・降順（常にフォルダー優先・名前は自然順）。右クリックまたは ☰ メニューから変更できます
- 絞り込みは種類（動画 / 音声 / 画像 / テキスト / フォルダー / その他）の個別切り替えと、名前での検索、取得済みのみ表示
- 素材のアップロード、フォルダ作成、削除に対応しています。エクスプローラーから一覧へファイルをドロップしてもアップロードできます
- 各行に **未取得 / 取得中 / 取得済み / 古い / 失敗** の状態が表示されます。クラウド側が更新されると「古い」になりますが、そのままドラッグすることも可能です
- ダウンロード先は「設定」タブの**アセット保存先**で変更できます（既定は `%LOCALAPPDATA%\YMM4CloudSync\Assets`）

> [!IMPORTANT]
> YMM4 は素材を**絶対パス**で参照します。アセット保存先のフォルダを移動・削除すると、
> その素材を配置済みのプロジェクトのリンクが切れます。

フォルダの削除は、中身が空の場合のみ行えます。また、クラウドから素材を削除しても、ダウンロード済みのローカルファイルは削除されません。

### WebDAV について

- 接続先は**複数登録できます**。「連携」タブの「WebDAV 接続を追加」から追加してください
- 接続には **https://** のサーバーを推奨します。`http://` は既定で拒否され、明示的に許可した場合のみ使用できます
- 認証方式は Basic / Digest / 自動 から選択できます（既定は Basic）
- Nextcloud / ownCloud で2要素認証を有効にしている場合は、通常のパスワードではなく**アプリパスワード**を使用してください
- Nextcloud / ownCloud では 16MB 以上のファイルを分割送信し、中断しても続きから再開できます。非対応のサーバーでは自動的に通常の送信に切り替わります
- 自己署名証明書を使う場合は、Windows の証明書ストア（信頼されたルート証明機関）への登録を推奨します。接続設定で証明書の検証を無効にすることもできますが、通信の傍受・改ざんを防げなくなります

## 動作確認済みバージョン

- YukkuriMovieMaker v4.55.1.1
- YukkuriMovieMaker v4.55.1.1 Lite

## 前提条件

- **YukkuriMovieMaker 4.55.1.1 以降** がインストールされていること
  - アセットタブが YMM4 のアイコン・コントロール・ファイル種別設定・タイムライン追加コマンドを利用するため、
    これより古いバージョンでは動作しません
- 対応クラウドサービスのアカウント  

## インストール手順

1. 本リポジトリの **Releases** ページからプラグインをダウンロードします。
2. ダウンロードしたファイルを実行し、画面の指示に従ってインストールしてください。
3. YMM4 を起動し、プラグインとして認識されていれば導入完了です。

## 使い方

1. YMM4 のツールタブから **YMM4 Cloud Sync** を開きます。
2. 「連携」タブでクラウドサービスと連携します。
3. プロジェクト一覧からアップロード・ダウンロード・開く操作を行います。
4. 素材を使い回したい場合は、「アセット」タブからアップロードし、取得した素材をタイムラインへドラッグします。

## 注意事項

- クラウド側の容量不足により、操作が失敗する場合があります。
- 同期中は YMM4 のプロジェクトを同時に複数環境で編集しないことを推奨します。
- 不具合が発生した場合、ログや状況を添えて Issue を作成してください。

## 設定について

### エラー報告 (Sentry DSN)

本プラグインは、不具合の早期発見と修正のため、Sentry を使用してエラー情報を収集しています。

- `appsettings.json` の Sentry DSN は意図的に公開されています
- Sentry DSN はクライアントアプリケーションで安全に公開できる設計です
- Sentry の初期化は本プラグイン専用のクライアントに閉じており、YMM4 本体や他プラグインで発生した例外は送信されません
- ユーザー名・メールアドレス・IP アドレスなどの識別情報は送信されません (`SendDefaultPii: false`)
- 例外メッセージやスタックトレースに含まれるファイルパスのうち、ユーザープロファイル配下 (`C:\Users\<ユーザー名>`) は送信前に `<user>` へ置換されます。それ以外のパス（プロジェクトの保存先やファイル名など）はそのまま送信されます
- エラー情報の送信を無効にしたい場合は、`appsettings.json` の `Dsn` を空文字列に設定してください
