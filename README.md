# YMM4 Cloud Sync

**YMM4 Cloud Sync** は、**YukkuriMovieMaker4**（以下、YMM4）のプロジェクトを  
**クラウドストレージと同期・管理**するためのプラグインです。

ローカル環境に依存せず、複数環境での作業やバックアップを簡単に行うことを目的としています。

> [!IMPORTANT]
> 本プラグインは **β版（開発中）** です。  
> 仕様変更や不具合が発生する可能性があります。

## 主な機能

- YMM4 プロジェクト（`.ymmx`）のクラウド保存
- クラウド上のプロジェクト一覧表示
- プロジェクトのダウンロード・削除
- クラウド上のプロジェクトを直接開いて編集
- プロジェクトを `.ymmx` ファイルとしてローカルに書き出し（クラウド連携なしで利用可能）
- 素材（アセット）のクラウド保存と、タイムラインへのドラッグ＆ドロップ配置

現在対応しているサービスは以下の通りになります。

- Google Drive（本プラグインが作成したファイルのみ）
- Dropbox（本プラグイン専用のアプリフォルダー内）
- OneDrive（本プラグイン専用のアプリフォルダー内）
- WebDAV (Nextcloud / ownCloud / InfiniCLOUD など)

※ 今後、対応クラウドサービスの追加を予定しています。

## 動作確認済みバージョン

- YukkuriMovieMaker v4.55.1.1
- YukkuriMovieMaker v4.55.1.1 Lite

## インストール手順

1. 本リポジトリのリリースページから **`YMM4CloudSync.ymme`** をダウンロードします。
2. ダウンロードした **`YMM4CloudSync.ymme`** を実行します。
3. 画面に表示される指示に従ってインストールを進めてください。
4. インストール完了後、YMM4 を起動し、プラグインとして認識されれば導入は完了です。

## 使い方

1. YMM4 のツールタブから **YMM4 Cloud Sync** を開きます。
2. 「連携」タブでクラウドサービスと連携します。
3. プロジェクト一覧からアップロード・ダウンロード・開く操作を行います。
4. 素材を使い回したい場合は、「アセット」タブからアップロードし、取得した素材をタイムラインへドラッグします。

## 注意事項

- YMM4 は素材を**絶対パス**で参照します。「設定」タブの**アセット保存先**を移動・削除すると、その素材を配置済みのプロジェクトのリンクが切れます。
- クラウド側の容量不足により、操作が失敗する場合があります。
- 同期中は YMM4 のプロジェクトを同時に複数環境で編集しないことを推奨します。
- 不具合が発生した場合、ログや状況を添えて Issue を作成してください。

## トラブルシューティング

### 「アセット」タブに素材が表示されない場合

- 「連携」タブでサインインが完了しているか確認してください。
- Google Drive では、本プラグインが作成したファイルのみが表示されます。ブラウザや Google ドライブアプリから直接配置した素材は一覧に表示されません。

### WebDAV サーバーに接続できない場合

- `http://` の接続は既定で拒否されます。**https://** のサーバーを使用してください。
- Nextcloud / ownCloud で 2 要素認証を有効にしている場合は、通常のパスワードではなく**アプリパスワード**を使用してください。
- 自己署名証明書を使用している場合は、Windows の証明書ストア（信頼されたルート証明機関）へ登録してください。

### プラグインが読み込まれていない場合

- YukkuriMovieMaker のバージョンが 4.55.1.1 以降か確認してください。
- インストール時にエラーが発生していなかったか確認してください。
- 必要に応じて YMM4 を再起動してください。
